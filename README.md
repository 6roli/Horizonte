# Horizonte

Recent Meteosat image sequences over Spain and the western Mediterranean, with explicit observation
times, sources and limitations. First app of a wider project on weather, extreme events, the ocean and the
coast. *Horizonte* is a provisional name, defined once in `src/config/app.ts` (`APP_NAME`) and `index.html`.

| | |
|---|---|
| Live app | https://horizonte.pages.dev |
| Portfolio | https://gabriel-olius.pages.dev |
| Data | EUMETSAT EUMETView WMS — Meteosat-12 (MTG-I1) FCI, public, no account |
| Hosting | Cloudflare Pages, Free plan · monthly cost €0 |

**Scope of v1:** observations only. No forecasts, estimates, detections, alerts or warnings.

## How it works

```
GitHub Actions (hourly, minute 17)
  └─ scripts/fetch-frames.ts
       1. GetCapabilities → which observation times exist for each layer
       2. pick 18 common times, 20 min apart (6 hours)
       3. GetMap → 1200×550 JPEG crop per layer and time (+ coastline overlay PNG)
       4. validate images and write public/data/live/manifest.json
  └─ vite build → dist/
  └─ wrangler pages deploy → Cloudflare Pages (static files on the CDN)

Browser
  └─ loads data/live/manifest.json
       ├─ valid → plays the sequence, flags it if stale (> 2.5 h) or outdated (> 6 h)
       └─ missing/invalid → loads data/sample/manifest.json, clearly labelled "Historical sample"
```

Visitors only download static files. Nothing a visitor does reaches EUMETSAT or runs any computation.

### Code layout

```
src/config/app.ts      App name, region, layers, time zone, thresholds  (no DOM — also used by scripts)
src/data/              Data access: manifest schema + validation, loading with fallback, freshness, preloading
src/ui/                Presentation: Leaflet map, playback rules, time formatting
src/main.ts            Wires data and UI together
src/i18n/en.ts         Interface strings (Spanish: add es.ts with the same keys)
scripts/fetch-frames.ts  Processing: download, validate, write manifest
scripts/lib/wms.ts       Pure WMS helpers (time dimension parsing, URL building)
public/data/sample/    Small committed historical sequence (800 px, ~1.7 MB)
public/data/live/      Generated by CI; ignored by Git
tests/                 Vitest unit tests
docs/data-sources.md   Source evaluation: interfaces, formats, licence, costs
```

## Data and licence

Images come from EUMETSAT's public Web Map Service. Under the EUMETSAT Data Policy, RGB composites and
visualisations of single channels served via WMS are *Advanced Image Products*, which are **Core data:
free and unrestricted under CC BY 4.0**, whatever their latency. Required attribution (Article 6.3), shown
on the map and in the footer:

> Contains modified EUMETSAT Meteosat data 2026

These are **images for viewing, not scientific data**: stretched, compressed and reprojected. Analysis needs
the original Level 1c numerical data from the EUMETSAT Data Store (free account; numerical data with less
than 1 hour latency is "Recommended" data and may not be redistributed). See
[docs/data-sources.md](docs/data-sources.md). No imagery is taken from Windy or other third-party viewers.

## Working in GitHub Codespaces

1. **Code → Codespaces → Create codespace on main.**
2. The container runs `npm ci` and `npm run fetch:live` (public data, no credentials).
3. `npm run dev` → the forwarded port 5173 opens in a preview tab.

Use **Open in VS Code Desktop** from the codespace menu to work from your local VS Code.

## Working in VS Code on your computer

Requirements: Node.js 24 LTS (scripts use Node's built-in TypeScript support) and Git.

```bash
gh repo clone 6roli/horizonte
cd horizonte
npm ci
npm run fetch:live   # optional: without it, the app shows the historical sample
npm run dev          # http://localhost:5173
```

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run fetch:live` | Download the latest sequence into `public/data/live/` |
| `npm run fetch:sample -- --end 2026-10-18T12:00:00Z --width 800 --note "…"` | Regenerate the committed sample |
| `npm run typecheck` | TypeScript, including scripts and tests |
| `npm test` | Unit tests (manifest validation, freshness, WMS time handling, playback, time zones) |
| `npm run build` | Type check + production build into `dist/` |
| `npm run verify` | All checks |

Options for `scripts/fetch-frames.ts`: `--kind live|sample`, `--end <ISO UTC>`, `--width`, `--count`, `--step` (minutes).

## Configuration

No secrets are needed to develop or to fetch data, so there is no `.env` file.
Deployment needs two repository secrets (*Settings → Secrets and variables → Actions*):

| Secret | Value |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Custom API token with **Account → Cloudflare Pages → Edit** only |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare account ID |

Without them, the workflow runs checks and skips deployment.

To change the region, layers, sequence length or thresholds, edit `src/config/app.ts`. Any WMS layer name
from `https://view.eumetsat.int/geoserver/wms?service=WMS&request=GetCapabilities` can be added to `LAYERS`;
give it an honest `kind` and explanation.

## Deployment and costs

`.github/workflows/build-deploy.yml`:

- **push** (any branch): type check, tests, fetch, build, deploy. `main` → production; other branches →
  `https://<branch>.horizonte.pages.dev`.
- **schedule** (hourly): fetch, build, deploy. If the fetch fails, the run fails and the previous deployment stays.
- **workflow_dispatch**: manual run.

This repository is private, so Actions minutes count against GitHub Free's 2,000 min/month. The scheduled
path takes about one billed minute (≈ 744 min/month). Without a payment method, GitHub blocks runs at the
quota rather than charging; the app would then show its "old data" warning. Cloudflare Pages Free does not
charge for static traffic and does not need a payment method.

GitHub Environments are not used: for private repositories on GitHub Free they are not available, and a single
production target does not need them.

## Limitations

- Images, not measurements (see above). Colours cannot be converted back to physical values.
- The time shown is the nominal scan start; a full-disc scan takes ~10 minutes.
- Parallax: high clouds appear shifted north by roughly 10 km or more at these latitudes.
- Hourly refresh plus EUMETView's publication delay: the newest frame is usually 20–90 minutes old.
- GeoColour at night uses a fixed background for land and city lights.
- The Canary Islands are outside the region.
- Not an official service. For warnings in Spain use [AEMET](https://www.aemet.es) and [Meteoalarm](https://meteoalarm.org).
