Ask the weather warehouse

Ask about the weather in Spain’s 52 provincial capitals. A small language model, fine-tuned for this warehouse, turns your question into SQL inside your browser, and DuckDB runs it on the live data. No server, no account.

    Where it goes wrong

    The 10 questions of the hand-written test set that the browser model got wrong, with the query it wrote and the right one. Most are a missing filter, a missing DISTINCT or a column taken from the wrong table. They were measured with ONNX Runtime on a CPU; on your graphics card the arithmetic differs slightly, so a few answers can come out differently.

    About this model

    • The model is Qwen2.5-Coder-1.5B-Instruct (Apache 2.0), fine-tuned with QLoRA on generated questions about the warehouse tables. Code, data and evaluation: weather-text2sql; weights: Hugging Face.
    • On 40 hand-written questions, a query counts as right when it returns the same data as the reference: the base model gets 7.5%, the fine-tuned model 87.5%, and this browser version (4-bit weights, 1.34 GB) 75%. The compression costs some detail.
    • Everything runs on your device: the model with WebGPU through transformers.js, the SQL with DuckDB-WASM over the warehouse’s public Parquet files. Your questions are not sent anywhere.
    • It is a demo, not a source of truth: the SQL can be wrong while looking plausible. Always read the query.
