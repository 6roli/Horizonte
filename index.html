Horizonte

Earth observation, weather and satellites over Spain and the western Mediterranean — a set of small, honest tools that share data and design.

Modules

    Shared by every module

    • Open data, credited

      Public sources only — EUMETSAT, Open-Meteo, AEMET — with their licence and attribution on every page.

    • Times you can trust

      Every value says when it was observed or forecast, in UTC and Spanish local time, and how old it is.

    • Static and private

      No Horizonte server, no accounts, no cookies, no tracking. Your browser fetches the public data directly.

    Horizonte is not an official service and issues no warnings. For official warnings in Spain see AEMET and Meteoalarm.

    Horizonte is a project by Gabriel Olius. Static site, no tracking, no cookies. Source code on GitHub.
